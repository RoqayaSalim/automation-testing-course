# Automation Testing Course

## About This Repository

Welcome to my Automation Testing learning repository!

This repository documents my learning journey in software test automation through course assignments, coding exercises, and hands-on practice. My goal is to strengthen my Java programming skills, understand automation testing concepts, and build a solid foundation for real-world testing projects.

## Learning Goals

- Strengthen Java fundamentals and Object-Oriented Programming (OOP).
- Understand variables, data types, conditions, loops, methods, and arrays.
- Practice writing clean, readable, and maintainable Java code.
- Learn UI test automation using Selenium WebDriver.
- Write and execute automated tests using TestNG.
- Understand the Page Object Model (POM) design pattern.
- Practice API testing and understand how UI and API tests complement each other.
- Use Git and GitHub for version control and project collaboration.
- Build practical automation testing projects and improve problem-solving skills.
